# Cinematic production pass

1. Replace the starting lighting choices with editable scene-aware film looks. Keep a fast preview and use the same camera and lighting evaluation for final render.
2. Create reusable actions in Blender and build a local animation exchange workflow for existing Minecraft rigs. Validate mapped bones, timing, source files, and unsupported data explicitly.
3. Add opt-in articulated eyes with editable expressions and deterministic blinking; keep original skin textures available unchanged.
4. Make a shot by composing a view and capturing a camera key. Add a visible rail, timed lens changes, path presets, predictable easing, and viewport recall.
5. Repair timeline navigation and destructive key moves. Add practical track filters, box selection, range tools, anchored zoom and bounded key rendering.
6. Verify the assembled workflow on Windows: import and apply a Blender action, capture camera keys, animate a face, preview a cinematic look and export a movie. Package the runnable editor and document the exchange format and limits.
