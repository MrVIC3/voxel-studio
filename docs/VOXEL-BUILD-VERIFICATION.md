# Voxel Build verification

Verified on this Windows PC with Minecraft Java 1.21.11, Java 21, Fabric Loader 0.18.4, Fabric API 0.141.6+1.21.11 and the installed Electron runtime.

- TypeScript compilation and Vite production build passed for the separate renderer.
- 12 build-engine tests passed: nested rotation/repetition and state transforms; bounded atomic plan compilation; shell/ellipse geometry; occupancy audits; spatial batching; authenticated service access; capture/draft/review/commit/verify/undo; ambiguous-submission retry using the same transaction ID; preservation of foreign edits; checkpoint/review invalidation; wrong-world/offline rejection; interrupted undo reconciliation; compact disk-backed receipt history with ordered multi-stage undo.
- The original animation editor's 34 tests passed.
- The actual Fabric GameTest server loaded the compiled bridge and passed all 2 required tests (Fabric's sanity check plus this project's HTTP integration test). The project test validates authentication, actual registry state canonicalization, invalid-property rejection, block-entity creation rejection, applying real blocks, reading their snapshot, idempotent duplicate submission, reuse-ID payload rejection, compare-and-set conflict rejection, inverse edits and final AIR restoration. It uses an isolated generated test world, not any world in the user's Minecraft installation. EULA auto-accept is disabled.
- A hidden Electron smoke test rendered a 7,537-cell offline watch-house/site from six directions, plus a closer perspective. PNG signatures and dimensions/content size were checked, all requested models/textures resolved, the entrance-clearance audit passed, and no renderer page errors occurred. Actual perspective, elevations and top PNGs were opened for visual review; the sample roof/gable and porch were corrected after the first review.
- The portable executable is tested separately by the same render smoke test after packaging. Skill structure, reference links, wrapper syntax and engine path are checked with `builder/check-skill.cjs`. The skill-creator Python validator passed for the maintained source, workspace discovery copy and installed global skill, using a workspace-local PyYAML dependency. The installed skill's wrapper also started the hidden portable engine and returned its status successfully.

Evidence is saved under `test-results/builder-render/report.json` and the Gradle game-test run logs under `mod/build/run`. The [preview](voxel-build-preview.png) and [front elevation](voxel-build-front.png) are actual engine output. Generated test files, dependency caches and releases are ignored by Git; source, example plans and skill instructions are retained.

Not verified: editing the user's own world, arbitrary modded blocks/resource packs, a long-running multi-district build, power-loss recovery under storage failure, or runtime redstone/fluid behavior. Journals, interruption handling and bounded transactions reduce risk but are not a whole-world backup or a whole-build atomic transaction. Build quality still requires Codex's actual visual judgment and live verification.
